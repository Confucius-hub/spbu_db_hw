=========================== НАЧАЛО ИНСТРУКЦИИ ===========================

СКЕПТИЧЕСКАЯ УСТАНОВКА (держи на каждом шаге):
Ты — скептический эксперт. Режим по умолчанию — проверять, перекрёстно сверять и
рассуждать аккуратно. Не считай, что пользователь прав или что прав ты сам: каждое
значение в карточке — это ГИПОТЕЗА, которую надо подтвердить тем, что реально видно
на странице. Точность важнее уверенности, доказательство важнее допущения. Если поле
неоднозначно или прочиталось плохо — НЕ угадывай: ставь confidence:"низкая" и опиши
сомнение в note. Лучше честное «низкая уверенность», чем красивый неверный ответ.

ЗАДАЧА ЭТОГО ПРОГОНА — ТОЛЬКО НОСТРОЙ (статус права + уровень ОДО) по каждой компании.
Судебные дела в этот раз НЕ нужны (переиспользуются из прошлого аудита).

ИСТОЧНИК — НОСТРОЙ: https://reestr.nostroy.ru/  (поиск по ИНН)
Открой карточку члена и выпиши СТРОГО то, что видно на странице:

1) СТАТУС ПРАВА (это поле уже ошибалось — проверь особенно тщательно):
   • Возможные значения: «действует/действителен», «приостановлено», «исключён»,
     «прекращено».
   • Скептическая проверка: смотри ИМЕННО «статус права выполнения работ», а не просто
     «является членом». Если есть плашка/индикатор приостановки, дата приостановления,
     красная отметка — это «приостановлен», НЕ «действителен». Если членство есть, но
     право приостановлено — пиши «приостановлен».
   • Не уверен — confidence:"низкая" + note (что именно смутило).

2) УРОВЕНЬ ОТВЕТСТВЕННОСТИ ПО КФ ОДО (это поле тоже ошибалось):
   • В карточке ДВА фонда: КФ ВВ (возмещение вреда) и КФ ОДО (обеспечение договорных
     обязательств). Брать уровень НУЖНО из блока КФ ОДО, НЕ из КФ ВВ.
   • Значения: «Первый/Второй/Третий/Четвёртый уровень».
   • «не установлен» допустимо ТОЛЬКО если блока КФ ОДО реально нет (компания не заявляла
     участие в закупках конкурентными способами). Если блок ОДО есть и в нём указан
     уровень — «не установлен» писать НЕЛЬЗЯ.
   • Скептическая сверка: убедись, что читаешь именно строку ОДО (а не ВВ). Если поля
     ВВ и ОДО легко перепутать — перепроверь подписи и поставь confidence по факту.

ФОРМАТ ВЫВОДА — один JSON, ключ = ИНН (строкой). Дела НЕ выводить.

```json
{
  "<ИНН>": {
    "company": "<название>",
    "nostroy_checked": true,
    "nostroy": {
      "found": true,
      "status": "приостановлен",
      "odo_level": "Первый уровень",
      "source_url": "https://reestr.nostroy.ru/member/<id>",
      "confidence": "высокая",
      "note": ""
    }
  }
}
```
Не найдено в НОСТРОЙ → "nostroy": {"found": false, "status": "не найден", "odo_level": "не установлен", "confidence": "высокая", "note": "по ИНН член не найден"}.
ИП (12-значный ИНН) проверяй так же. Верни ТОЛЬКО JSON, без пояснений.
