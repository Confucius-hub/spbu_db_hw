# Аудит членов СРО — реестр договоров ОДО на 08.06.2026

Третий прогон по той же методике (`../audit/`, `../audit_2026-05-21/`), исходник —
реестр договоров **на 08.06.2026** (91 компания, 445 договоров, штрафы 127,55 млн ₽).

## Скептический режим

Анализ и промт расширения работают в режиме «скептического эксперта»: каждое значение —
гипотеза, которую подтверждаем тем, что видно в источнике; неуверенность проговаривается
явно (`confidence`/`note`), точность важнее уверенности. Установка вшита в начало
`EXTENSION_COMMAND.md`.

## Решение по сбору данных (08.06)

Все 91 компания уже встречались в прошлых аудитах (67 из `../audit/` + 89 из
`../audit_2026-05-21/`, вместе ровно 91). По согласованию:

- **НОСТРОЙ (статус права + уровень ОДО) — перепроверяется ЗАНОВО** по всем 91.
  Причина: статусы волатильны (приостановки), и именно здесь расширение давало ошибки.
  Промт усилен прицельной защитой: статус «приостановлен↔действителен» и уровень
  «КФ ВВ↔КФ ОДО».
- **Судебные дела — ПЕРЕИСПОЛЬЗОВАНЫ** (89 из аудита-2, 2 из аудита-1). При необходимости
  обновляются через приложение к промту (Rusprofile + КАД).

В `collected_data.json` дела засеяны (`cases_checked: true`), а НОСТРОЙ помечен ожидающим
(`nostroy_checked: false`) — до загрузки свежих статусов от расширения.

## Отличие исходника

Файл 08.06 содержит **22 колонки** (в 21.05 было 24: без хвостовых «Количество» и
«ДатаПоследняя»). Первые 14 колонок (имя, ИНН, статус в СРО, вид, стоимость, штрафы)
совпадают позиция-в-позицию, поэтому агрегация не пострадала.

## Файлы

- `build_report.py` — пайплайн (копия, логика та же).
- `companies.csv` — 91 компания (имя, ИНН, вид, договоры, сумма, штрафы).
- `collected_data.json` — дела переиспользованы, НОСТРОЙ ожидает.
- `EXTENSION_COMMAND.md` — промт по НОСТРОЙ (8 батчей) + приложение Rusprofile/КАД.
- `source/contracts_registry_2026-06-08.xls` — исходный реестр.
- `audit_report_corrected.xlsx` — результат.

## Модель риска (та же)

Высокий — НОСТРОЙ приостановлен/исключён, ОДО не установлен, есть дела по подряду 2025+,
штрафы ≥ 1 000 000 ₽. Средний — небольшие штрафы / спорные данные. Низкий — НОСТРОЙ
действителен, ОДО установлен, дел нет, штрафов нет. Пока НОСТРОЙ не проверен —
строка остаётся «⏳ ожидает данных», а не «Низкий».
