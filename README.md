# СРО «СССС» — корпоративный портал

Production-grade корпоративный портал саморегулируемой организации «Строительный союз
Северной столицы»: премиальный UX/UI, полноценная новостная система, онлайн-калькулятор
стоимости вступления, приём заявок и админ-панель управления контентом.

> Полный редизайн и переархитектура сайта [sro-ssss.ru](https://sro-ssss.ru/).

---

## Технологический стек

| Слой        | Технологии                                                        |
| ----------- | ----------------------------------------------------------------- |
| Frontend    | **Next.js 16** (App Router, RSC), **React 19**, **TypeScript**    |
| Стилизация  | **Tailwind CSS v4** (дизайн-токены через `@theme`), премиум navy + gold |
| Backend     | Next.js **Route Handlers** (REST API), валидация **Zod**          |
| База данных  | **Prisma ORM** + **SQLite** (ноль настройки; легко мигрируется на PostgreSQL) |
| Контент     | Markdown-статьи (`react-markdown` + `remark-gfm`)                 |
| Иконки      | `lucide-react`                                                    |
| SEO         | Метаданные, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`      |

---

## Быстрый старт (macOS)

Требуется **Node.js 18.18+** (рекомендуется 20+) и npm.

```bash
# 1. Установить зависимости (автоматически сгенерирует Prisma Client)
npm install

# 2. Создать и заполнить локальную базу данных (SQLite + демо-новости 2026)
npm run setup

# 3. Запустить dev-сервер
npm run dev
```

Откройте **http://localhost:3000**.

Production-сборка и запуск:

```bash
npm run build
npm run start
```

## Переменные окружения

Файл `.env` уже создан со значениями по умолчанию. Для продакшена обязательно поменяйте
пароль и секрет.

```env
DATABASE_URL="file:./dev.db"          # SQLite-файл базы
ADMIN_PASSWORD="sro-admin-2026"       # пароль входа в /admin
ADMIN_SESSION_SECRET="..."            # секрет для подписи сессии (длинная случайная строка)
NEXT_PUBLIC_SITE_URL="http://localhost:3000"  # для canonical/OG/sitemap
```

## Ключевые возможности

- **Современный premium-дизайн** — единая система токенов (navy + золото), типографика
  (Inter + Manrope), сетки, мягкие тени, сдержанные анимации, тёмные акцентные секции.
- **Адаптивность mobile-first** — отдельное выезжающее мобильное меню, крупные touch-цели.
- **Новостная система** — featured-материал, рубрики, теги, поиск (с поддержкой кириллицы),
  пагинация, похожие статьи, кнопки «поделиться», SEO-разметка `NewsArticle`.
- **Калькулятор стоимости** — мгновенный расчёт взносов в компенсационные фонды по реальным
  уровням ответственности; компактный вариант в Hero и полный — на странице «Вступление».
- **Приём заявок** — обратный звонок, консультация, заявка на вступление, расчёт; валидация
  на сервере, защита от спама (honeypot), сохранение в БД, просмотр в админке.
- **Чистый backend** — модульные API-роуты, единый слой данных, валидация Zod.
- **SEO** — `sitemap.xml`, `robots.txt`, canonical, Open Graph, JSON-LD (Organization,
  Breadcrumb, FAQ, NewsArticle).

## Замечания

- **База данных.** По умолчанию SQLite — нулевая настройка для локального запуска. Для
  продакшена смените `provider` на `postgresql` в `prisma/schema.prisma` и обновите
  `DATABASE_URL`, затем выполните `npm run db:push`.
- **Изображения.** Обложки новостей генерируются как фирменные градиенты (без внешних
  зависимостей). Реальные документы для раздела «Документы» добавляйте в каталог `/public`
  и обновляйте ссылки в `src/lib/documents.ts`.
- **Контент.** Большая часть статических текстов (навигация, услуги, отзывы, FAQ, реквизиты)
  редактируется в одном файле — `src/lib/site.ts`.
