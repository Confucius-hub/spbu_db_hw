# Фотографии сайта

Положите сюда файлы с указанными именами — и они **автоматически** появятся на сайте
(перезапуск не нужен в dev, в проде — после пересборки). Пока файла нет, на его месте
показывается фирменный градиент, поэтому сайт никогда не выглядит «сломанным».

Рекомендуемый формат: **JPG/WebP, ширина 1600–1920 px, вес до ~300 КБ**
(сожмите на squoosh.app или tinypng.com).

## Нужные файлы

| Имя файла                  | Где используется                         | Что на фото (рекомендация)            |
| -------------------------- | ---------------------------------------- | ------------------------------------- |
| `hero.jpg`                 | Главный экран (первый блок)              | Современная застройка / панорама СПб  |
| `construction.jpg`         | Шапки внутренних страниц, CTA-блок       | Стройплощадка, кран, объект           |
| `team.jpg`                 | (резерв) блоки «о нас», услуги           | Инженеры/специалисты на объекте       |
| `news-legislation.jpg`     | Обложки новостей рубрики «Законодательство» | Документы, право, печать           |
| `news-industry.jpg`        | Обложки рубрики «Отрасль»                | Строительство, техника                |
| `news-sro.jpg`             | Обложки рубрики «Деятельность СРО»       | Заседание, деловая встреча            |
| `news-nostroy.jpg`         | Обложки рубрики «НОСТРОЙ и НРС»          | Архитектура, фасады, город            |
| `news-guides.jpg`          | Обложки рубрики «Полезное»               | Чертежи, проектирование               |

## Где это настроено

Пути заданы в `src/lib/site.ts` → объекты `media` и `newsCategoryImages`.
Если хотите другие имена/пути — поменяйте там.

## Лицензия

Используйте только фото, на которые у вас есть права (собственные съёмки или
стоковые фото со свободной лицензией: Unsplash, Pexels, Pixabay и т.п.).
