# Документы СРО (PDF)

Положите сюда PDF-файлы документов с указанными именами. После этого в
`src/lib/documents.ts` у соответствующей записи поменяйте `href: null` на путь к файлу,
например `href: "/docs/ustav.pdf"` — и на странице «Документы» вместо плашки
**«Готовится»** появится кнопка **«Скачать»**.

> Содержимое документов НЕ выдумывается. Пока реальных файлов нет — документы помечены
> «Готовится», а скачать актуальную версию можно по кнопке «Запросить документ».
