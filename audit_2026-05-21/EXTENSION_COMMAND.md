## Инструкция (вставляется ОДИН раз, перед списком батча)

=========================== НАЧАЛО ИНСТРУКЦИИ ===========================

Ты — помощник по комплаенс-проверке. По каждой компании из списка собери данные
с ДВУХ источников и в конце выведи ОДИН блок JSON (схема в конце).
Работай ВНИМАТЕЛЬНО и ТЩАТЕЛЬНО, ничего не выдумывай.

ИСТОЧНИК 1 — RUSPROFILE (есть платный доступ): https://www.rusprofile.ru/  (поиск по ИНН)
  • Открой карточку компании → раздел «Арбитражные дела» / «Судебная практика».
  • Просмотри ВСЕ дела (пролистай ВСЕ страницы пагинации, не только первую).
  • ФИЛЬТР, строго в таком порядке:
      (1) СНАЧАЛА оставь ТОЛЬКО дела, у которых «Категория» содержит слово
          «подряд» (в любой форме: «…по договорам подряда», «строительный
          подряд», «субподряд» и т.п.).
          Категории БЕЗ слова «подряд» (поставка, аренда, заём/кредит, лизинг,
          энергоснабжение, банкротство, налоги, взносы, страхование, услуги
          и пр.) — ПОЛНОСТЬЮ игнорируй.
      (2) ПОТОМ из оставшихся возьми ТОЛЬКО с датой регистрации ≥ 01.01.2025.
  • По КАЖДОМУ подходящему делу открой карточку дела и выпиши ВСЕ поля:
      - case_number   — номер дела (напр. А53-11445/2025)
      - reg_date      — дата регистрации (дд.мм.гггг)
      - category      — категория полностью
      - type          — тип спора (напр. «Экономические споры по гражд. правоотношениям»)
      - plaintiff     — истец
      - defendants    — ответчики (НЕ оставляй пустым — бери из карточки)
      - other_party   — третье / иное лицо
      - our_role      — роль ПРОВЕРЯЕМОЙ компании: «истец» / «ответчик» / «третье лицо»
      - claim_amount  — сумма иска (число, без пробелов и «₽»)
      - outcome       — исход (выиграно / проиграно / частично / —)
      - status        — текущий статус (Завершено / В процессе / На рассмотрении)
      - kad_url       — ТОЧНЫЙ href вида https://kad.arbitr.ru/Card/<полный-uuid>
                        (НЕ вид ?number=…).
  • Если после фильтра дел НЕТ — это валидный результат: podryad_cases_2025plus: [].

ИСТОЧНИК 2 — НОСТРОЙ: https://reestr.nostroy.ru/  (поиск по ИНН)
  • Открой карточку члена. Зафиксируй «статус права»:
      «действителен» / «приостановлен» / «исключён» / «прекращено».
  • Уровень ответственности бери ПО КФ ОДО (компенсационный фонд ОБЕСПЕЧЕНИЯ
    ДОГОВОРНЫХ ОБЯЗАТЕЛЬСТВ — «обязательства по договорам подряда конкурентными
    способами»): «Первый/Второй/Третий/Четвёртый уровень» либо «не установлен».
    НЕ ПУТАЙ с КФ ВВ (возмещение вреда). Если фонда ОДО нет (прочерк) → "не установлен".

ФОРМАТ ВЫВОДА — один JSON-объект, ключ = ИНН (строкой). checked-флаги = true:

```json
{
  "<ИНН>": {
    "company": "<название>",
    "nostroy_checked": true,
    "cases_checked": true,
    "rusprofile_url": "<url карточки>",
    "nostroy": {"found": true, "status": "действителен", "odo_level": "Первый уровень", "source_url": "https://reestr.nostroy.ru/member/<id>"},
    "podryad_cases_2025plus": [
      {"case_number":"А53-11445/2025","reg_date":"03.04.2025","category":"...подряда","type":"Экономические споры по гражданским правоотношениям","plaintiff":"...","defendants":"...","other_party":"","our_role":"ответчик","claim_amount":3030897.47,"outcome":"Частично","status":"Завершено","kad_url":"https://kad.arbitr.ru/Card/<uuid>"}
    ]
  }
}
```

Правила: компания не в НОСТРОЙ → "nostroy": {"found": false, "status": "не найден", "odo_level": "не установлен"}.
ИП (физлица по 12-значному ИНН) тоже проверяй в НОСТРОЙ и в арбитраже по тому же алгоритму.
Верни ТОЛЬКО JSON, без пояснений.
