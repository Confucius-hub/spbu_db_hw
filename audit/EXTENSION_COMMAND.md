# Команда для браузерного расширения Claude (сбор данных по членам СРО)

> Скопируйте текст между линиями `=====` в расширение Claude в браузере.
> Можно прогонять весь список сразу или порциями по 10–15 ИНН (см. блок «Список компаний»).
> Расширение должно вернуть **только JSON** в указанном формате — я подставлю его в отчёт.

=========================== НАЧАЛО КОМАНДЫ ===========================

Ты — помощник по комплаенс-проверке. По каждой компании из списка ниже собери
данные с ДВУХ сайтов и верни строго в формате JSON (схема в конце). Действуй
по ИНН. Если данных нет — честно ставь found:false / пустые значения, ничего не выдумывай.

ШАГ 1. НОСТРОЙ — реестр членов: https://reestr.nostroy.ru/
  • Найди компанию по ИНН, открой карточку члена.
  • Зафиксируй «статус права» (право выполнять работы): одно из
    «действителен» / «приостановлен» / «исключён» / «прекращено».
  • Зафиксируй УРОВЕНЬ ОТВЕТСТВЕННОСТИ ПО ОДО — именно по компенсационному фонду
    ОБЕСПЕЧЕНИЯ ДОГОВОРНЫХ ОБЯЗАТЕЛЬСТВ (КФ ОДО, «Размер обязательств по договорам
    подряда с использованием конкурентных способов заключения договоров»):
    «Первый/Второй/Третий/Четвёртый уровень ответственности» ИЛИ «не установлен».
    ВНИМАНИЕ: не путай с уровнем по КФ ВВ (возмещение вреда). Нужен уровень ОДО.
    Если у члена нет фонда ОДО — пиши odo_level: "не установлен".

ШАГ 2. RUSPROFILE — арбитражные дела: https://www.rusprofile.ru/  (поиск по ИНН)
  • Открой карточку компании → раздел «Арбитражные дела» / «Судебная практика».
  • ВАЖНО, порядок фильтрации именно такой:
      (1) СНАЧАЛА оставь только дела, у которых КАТЕГОРИЯ содержит слово «подряд»
          (например: «О неисполнении или ненадлежащем исполнении обязательств
          по договорам подряда», «…по договору строительного подряда» и т.п.).
          Дела других категорий (поставка, лизинг, банкротство, налоги, страхование,
          взносы и пр.) — ИГНОРИРУЙ полностью.
      (2) ПОТОМ из оставшихся возьми только те, где дата регистрации ≥ 01.01.2025.
  • По каждому подходящему делу выпиши: номер, дату регистрации, категорию, тип,
    истца, ответчиков, иное/третье лицо, сумму иска, исход, текущий статус
    (Завершено / В процессе / На рассмотрении).
  • Определи РОЛЬ проверяемой компании в деле: «истец» / «ответчик» /
    «третье лицо» (смотри, в каком списке стоит её название).
  • Ссылку на карточку дела возьми из ссылки «На сайте КАД» (её href).
    Если её нет — поставь https://kad.arbitr.ru/Card?number=<номер дела>.

ФОРМАТ ВЫВОДА — один JSON-объект, ключ = ИНН (строкой):

```json
{
  "<ИНН>": {
    "company": "<название>",
    "checked": true,
    "rusprofile_url": "<url карточки>",
    "nostroy": {
      "found": true,
      "status": "приостановлен",
      "odo_level": "не установлен",
      "source_url": "<url карточки НОСТРОЙ>"
    },
    "podryad_cases_2025plus": [
      {
        "case_number": "А53-11445/2025",
        "reg_date": "03.04.2025",
        "category": "О неисполнении или ненадлежащем исполнении обязательств по договорам подряда",
        "type": "Экономические споры по гражданским правоотношениям",
        "plaintiff": "отсутствует",
        "defendants": "ООО \"Энтэл\", Ассоциация \"ОРС\"",
        "other_party": "НКО \"Фонд Капитального Ремонта\"",
        "our_role": "ответчик",
        "claim_amount": 3030897.47,
        "outcome": "Частично проиграно",
        "status": "Завершено",
        "kad_url": "https://kad.arbitr.ru/Card?number=А53-11445/2025"
      }
    ]
  }
}
```

Правила: если дел по подряду 2025+ нет — "podryad_cases_2025plus": [].
Если компания не найдена в НОСТРОЙ — "nostroy": {"found": false, "status": "не найден", "odo_level": "не установлен"}.
Суммы — числом (без пробелов и «₽»). Верни ТОЛЬКО JSON, без пояснений.
