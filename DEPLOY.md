# Как получить публичную ссылку на сайт

> Важно: сборка проекта выполнялась в изолированном окружении без доступа к
> интернету и сервисам деплоя, поэтому публичный адрес создаётся из вашего
> аккаунта (бесплатно). Ниже — три пути: мгновенно посмотреть локально и два
> способа получить настоящую ссылку.

Репозиторий уже на GitHub: **confucius-hub/spbu_db_hw**, ветка
`claude/lucid-goodall-ytjrG`.

---

## Вариант 0. Посмотреть прямо сейчас (локально, 2 минуты, без аккаунтов)

```bash
git clone <repo> && cd spbu_db_hw
git checkout claude/lucid-goodall-ytjrG
npm install
npm run dev
```

Открыть **http://localhost:3000**. Это полностью тот же продакшен-билд.

---

## Вариант A. Публичная ссылка через Render (быстрее всего, без внешней БД)

Подходит для демо: использует репозиторий «как есть» (SQLite), база создаётся и
наполняется при старте автоматически.

1. Зарегистрируйтесь на <https://render.com> (бесплатно, вход через GitHub).
2. **New → Blueprint**, выберите репозиторий `spbu_db_hw` и ветку
   `claude/lucid-goodall-ytjrG`. Render прочитает файл `render.yaml`.
3. При создании укажите переменные:
   - `ADMIN_PASSWORD` — ваш пароль для `/admin` (или оставьте — будет дефолтный).
   - `NEXT_PUBLIC_SITE_URL` — после первого деплоя впишите выданный адрес вида
     `https://sro-ssss-portal.onrender.com`.
4. **Apply** → дождитесь сборки. Через 3–5 минут получите публичную ссылку.

> Примечание: на бесплатном тарифе файловая система временная — заявки и правки
> новостей сбрасываются при перезапуске сервиса (база каждый раз пересоздаётся
> со свежими демо-новостями). Для постоянного хранения используйте Вариант B.

---

## Вариант B. Продакшен через Vercel + Postgres (рекомендуется для боевого сайта)

Лучший вариант для Next.js. Нужна внешняя БД (на бессерверном Vercel SQLite
не работает). Бесплатный Postgres — Neon или Vercel Postgres.

1. Создайте бесплатную БД: <https://neon.tech> → скопируйте строку подключения
   `postgresql://...`.
2. В `prisma/schema.prisma` смените провайдер:
   ```prisma
   datasource db {
     provider = "postgresql"
     url      = env("DATABASE_URL")
   }
   ```
3. Импортируйте репозиторий на <https://vercel.com> (**Add New → Project**).
4. В **Environment Variables** добавьте:
   - `DATABASE_URL` = строка подключения Postgres
   - `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`
   - `NEXT_PUBLIC_SITE_URL` = адрес вашего домена на Vercel
5. Деплой. После первого деплоя один раз примените схему и сид:
   ```bash
   # локально, указав облачный DATABASE_URL:
   DATABASE_URL="postgresql://..." npx prisma db push
   DATABASE_URL="postgresql://..." npm run db:seed
   ```
6. Готово — постоянный публичный сайт с сохранением заявок и новостей.

> Я могу подготовить отдельную ветку под Postgres (смена провайдера + проверка
> миграции), чтобы Вариант B свёлся к «нажать Deploy». Скажите — сделаю.

## Что выбрать

- **Просто увидеть прод сейчас** → Вариант 0 (локально) или Вариант A (Render).
- **Боевой постоянный сайт с доменом** → Вариант B (Vercel + Neon).
